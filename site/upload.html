Worldwide Rig Count (.xlsx) fra Baker Hughes legges i raw/ i GitHub-repoet. Siden oppdateres automatisk etter et par minutter.

1. Hent filen

Last ned «Worldwide Rig Count» fra rigcount.bakerhughes.com/intl-rig-count.

2. GitHub-token

Slik lager du et token
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → .
  3. Permissions → Repository permissions → Contents: Read and write. Ingenting annet.
  4. Velg en utløpsdato (f.eks. 1 år), generer og lim inn over.

Tokenet sendes bare til api.github.com og lagres aldri i repoet. Uten avkrysning glemmes det når fanen lukkes.
